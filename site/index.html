How to read this. The court publishes one table row per defendant an order concerns, and sometimes splits a single order across several one-page PDFs. The 434 published entries therefore resolve to the 149 orders listed here. Each download is the complete order, reassembled where the court had split it.

Known gaps. Entry 50 (18 Jan 2021) was never uploaded by the court — eCourts returns “File Is Not Uploaded”. Entries 141 and 164 are absent from the archives supplied; entry 164 is the only entry on 22 Jul 2025, so that date has no document. The true order count is 149–151, with 149 confirmed.

On the summaries. Every accused number, section, citation and date in this table was checked back against the text of the order it is attributed to. The characterisation of an argument is editorial judgment and has not been reviewed by a lawyer. Read the PDF before relying on any entry.

On search. Search runs in your browser over the text extracted from each order; nothing you type is sent anywhere. Text extraction can miss words in poorly scanned pages, so a search that finds nothing is not proof an order does not mention it. To find orders described in everyday words, search also uses a short plain-English description of each order, written by AI from the order text; names and numbers in these were checked against the order, but they have not been reviewed by a lawyer. When one is the reason an order matched, it is shown with an amber label. Rely on the order itself.
